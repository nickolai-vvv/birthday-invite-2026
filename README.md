# Birthday Invite 2026

Интерактивное приглашение на день рождения: поездка на Сонате, мини-игра «Шашки», знакомство с гостями и финальный тост в гараже.

## Стек

Next.js App Router, React, TypeScript, Three.js, React Three Fiber и Drei. Версии зависимостей зафиксированы в `package-lock.json`.

## Запуск

Используйте Node.js 22 LTS и npm.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Для текущей версии переменные окружения не требуются.

## Проверка и production

```sh
npm run typecheck
npm run build
npm start
```

`typecheck` запускайте после установки зависимостей и первого запуска или сборки Next.js, которые создают служебные типы. `start` запускает готовую production-сборку.

## Структура

```text
src/
  app/
    layout.tsx                 # Общий layout, метаданные, глобальные стили
    page.tsx                   # Серверная точка входа страницы
    globals.css                # Стили страницы и мобильного интерфейса
  components/
    InvitationExperience.tsx   # Клиентский сценарий, прокрутка и переходы
    ui/                        # Приборы, управление, карточки и загрузка
    scene/                     # 3D-сцена, персонажи, окружение и реквизит
  lib/scene/                   # Физика гонки, маршруты и генераторы геометрии
  data/                        # Описания гостей и данные анимаций
public/models/                 # Используемые в приложении модели и текстуры
work/source-models/            # Исходные модели, локальный архив вне Git
```
